# ADR-014：工具链与目标平台的范围划分

- 状态：暂定（待依赖兼容性与构建验证后冻结）
- 日期：2026-10-25（修订）
- 来源：P0 决策，对应 ASTER-ARCH-001 ADR-012 与 `docs/规范/07-后续开发规划.md` P0-7

## 背景

ARCH-001 要求第一版明确支持的 CPU 架构与最低系统版本。开发工具能否在某系统运行，与最终生成的应用支持什么系统是两件事。过早锁定产品的最低版本会不必要地限制 Aster 的能力；过早承诺工具链版本也可能与依赖不兼容。因此需要把两者分开定义。

## 决策

| 对象 | 决策 | 状态 |
|---|---|---|
| Aster 工具链（编译器、CLI、Spike 工具）的最低 macOS 版本 | macOS 12 作为 Spike 阶段的验证基线 | 暂定 |
| CPU 架构（工具链与 Spike） | x86_64 与 ARM64 都纳入目标 | 暂定 |
| 最终生成应用的最低 macOS 版本 | 暂不锁定；完成依赖兼容性与构建验证后决定 | 未决定 |
| Windows 与 Linux | 保留为正式跨平台目标，分别验证 | 已确定方向 |

## 当前验证状态

- 已在 macOS 12.7.6、x86_64 上完成构建与测量（`benchmarks/results/2026-10-25-macos-b1-slint.json`）。
- ARM64 尚未验证。在 Apple Silicon 设备或 CI 运行器上构建之前，不得声称支持 ARM64。
- 最终应用的最低版本取决于 Slint 等依赖的最低系统要求，尚未检查。

## 理由

- 把工具链基线设为 macOS 12，与当前可用的验证环境一致，不因此限制最终应用。
- 最终应用的最低版本应由依赖实际支持范围和构建结果决定，而不是由开发环境推断。

## 后果

- 性能数据只适用于 macOS 12.7.6 / x86_64，不得推广到其他配置。
- 在 ARM64 验证之前，文档中的"支持架构"只能写"计划中"。

## 修改条件

- 依赖检查确认最终应用的最低系统版本后，更新为"已确定"。
- ARM64 构建与基准通过后，更新架构支持声明。
- 若某个关键依赖不再支持 macOS 12，需要重新评估工具链基线。
