# ADR-014：第一个目标平台与最低系统版本

- 状态：待确认（需要项目维护者决定最低系统版本）
- 日期：2026-10-25
- 来源：P0 决策，对应 ASTER-ARCH-001 ADR-012 与 `docs/规范/07-后续开发规划.md` P0-7

## 背景

ARCH-001 要求跨平台支持 Windows、macOS、Linux，但也要求"不把理论上能编译视为正式支持"，并且第一版必须明确支持的 CPU 架构与最低系统版本。P0 的 Spike 与 EXP-001 需要一个可以实际运行和测量的平台。

## 当前环境

- 开发机：macOS 12.7.6（Darwin），Intel x86_64（i5-6267U），内置 Retina 显示屏。
- 已完成的测量全部在该机器上进行（`benchmarks/results/2026-10-25-macos-b1-slint.json`）。
- 本机无 Windows 与 Linux 环境，无法在 P0 验证这两个平台。

## 备选方案

- macOS 优先：开发机与 CI 都可直接使用，已有测量数据。缺点：Apple Silicon 与 Intel 的差异需要分别验证；最低系统版本需要确定。
- Windows 优先：桌面用户面广，输入法与 DPI 行为差异大，适合提前暴露风险。缺点：需要新的开发与测试环境。
- Linux 优先：工具链与 CI 成本低。缺点：窗口系统与输入法的碎片化较严重，不适合作为首个用户平台。

## 决策（建议，待确认）

- 第一个开发与测试平台为 macOS，因为它是当前唯一可以完整运行 P0 实验的环境。
- Windows 与 Linux 在 P6 之前加入 CI 矩阵；P2 出口门禁前必须至少在一个非 macOS 平台上运行 B1。
- 最低 macOS 版本、CPU 架构（Intel、Apple Silicon 或两者）**尚未决定**，需要项目维护者确认。本 ADR 不自行决定。

## 理由

P0 的目标是验证假设，而不是覆盖全部平台。选择唯一可用的平台可以让实验和测量保持同场条件（05 section 4.1）。

## 后果与影响范围

- P0 的所有性能数据只适用于 macOS 12.7.6 与 Intel x86_64，不得推广到其他平台。
- CI 当前只配置 macOS 运行器（`.github/workflows/ci.yml`）。
- 中文输入法与 DPI 的人工检查（`benchmarks/results/spike-a-manual-check.md`）只能在 macOS 上完成。

## 修改条件

- 维护者确定最低系统版本或 CPU 架构支持范围后，本 ADR 更新为"已确定"。
- 若 P2 出口时发现 macOS 上的输入法或布局问题无法在其他平台复现，需要重新评估平台优先级。
