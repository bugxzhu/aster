# ADR-015：项目许可证

- 状态：待确认（需要项目维护者决定；LICENSE 文件尚未创建）
- 日期：2026-10-25
- 来源：P0 决策，对应 `docs/规范/06-仓库-代码规范-贡献指南.md` §8

## 背景

发布前必须确定核心代码的许可证。许可证影响商业采用、专利授权与贡献者协议。基础设计文档 §9 与设计讨论建议核心采用 Apache-2.0。

## 备选方案

- Apache-2.0：包含明确的专利授权条款，对商业采用友好，设计讨论的建议。
- MIT：简单，兼容性广，但没有明确的专利授权条款。
- 双许可（例如 Apache-2.0 OR MIT）：Rust 生态常见做法，允许使用者选择。缺点：需要额外的说明与维护。

## 当前状态

- 仓库中的 `Cargo.toml` 已声明 `license = "Apache-2.0"`，这是**建议值**，不是已确定的法律决定。
- `LICENSE` 与 `NOTICE` 文件尚未创建。
- 字体、图标、示例素材的许可证需要逐项登记（06 §8.1），尚未进行。

## 决策

待项目维护者确认。在确认之前：

- 不创建 `LICENSE` 文件；
- 不发布任何包或发行版本；
- 第三方依赖（Slint、serde、toml 等）的许可证需要在 P5 包管理阶段前逐项核对。

## 理由

Apache-2.0 与设计讨论的建议一致，但最终选择影响长期贡献者与用户，必须由项目维护者决定。

## 后果与影响范围

- `Cargo.toml` 中的 `license` 字段需要在确定后同步更新。
- 贡献者协议（DCO 或 CLA）的选择与许可证一并决定（06 §8.2）。
- Slint 是 P0 原型依赖，其许可证需要在确定 Spike 结论的去向前核对。

## 修改条件

维护者确定许可证后，本 ADR 更新为"已确定"，并创建 `LICENSE` 与 `NOTICE`。
