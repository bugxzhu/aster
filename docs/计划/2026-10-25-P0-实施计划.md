# Aster P0 实施计划

> **For agentic workers:** Execute task by task. Steps use checkbox (`- [ ]`) syntax for tracking. Do not start a task until the previous task's verification passes.

**Goal:** 完成 P0 阶段：建立可构建的仓库骨架与 CI 检查，启动 UI Spike 01（原型 A 与 B），完成 EXP-001 的 B1 基线，并形成 G0 门禁评审记录。

**Architecture:** 单仓库 Rust workspace。`xtask` 负责仓库策略检查（英语源码、ID 与格式）。Spike 代码位于 `spikes/`，不被 `crates/` 依赖。B1 基准应用位于 `benchmarks/apps/`。

**Tech Stack:** Rust（工具链由 `rust-toolchain.toml` 固定），Slint 1.x（最新稳定版，执行时记录于 `Cargo.lock`），serde / serde_json，GitHub Actions（CI 定义）。

**Spec:** `docs/规范/00-设计文档索引与决策总表.md`、`docs/规范/06-仓库-代码规范-贡献指南.md`、`docs/规范/07-后续开发规划.md`、`docs/规范/02-UI-布局与渲染架构规范.md`、`docs/规范/05-基准应用与性能测试计划.md`、`docs/设计原始文档/技术验证阶段.md`

## Global Constraints

- 源码、注释、标识符、诊断源文本、日志、提交信息：只允许英语，不得出现中文字符（06 §3.0）。数据文件 `locales/*.toml` 与白名单中的测试数据例外。
- 布局单位为逻辑像素 `dp`（02 §4）。
- 工具链版本由 `rust-toolchain.toml` 固定；升级必须单独提交（06 §2）。
- `spikes/` 中的代码不得被 `crates/` 依赖（06 §1.1）。
- `ui/` 语义层（`aster-ui-model`）不得依赖任何渲染后端（02 §11.5、06 §1.2）。
- 不对外宣传未经同场测量的性能数字（05 §5、§8）。
- 不修改任何已冻结或验收用的期望值以使测试通过（设计讨论硬规则 5，03 §6.4）。
- 提交信息使用 Conventional Commits，英文（06 §4.2）。

## Review Focus

以下五类输入或条件最可能在真实使用中出错，每项都有对应的测试或检查步骤。

1. **中文输入法组合输入与候选窗口定位**（TextInput 中输入拼音）。预期：组合文本可见，候选窗口贴近光标，提交后文字正确。→ Task 6 Step 9（手动检查清单，EXP-005 的前置）。
2. **译文变长导致布局溢出**（如伪本地化或较长的 zh-CN 文本）。预期：报告 `LAYOUT_CONFLICT`，不静默截断。→ Task 5 测试 `pseudo_long_label_reports_conflict`。

5. **DPI 或显示缩放变化**（100% 切换到 200%）。预期：布局 dp 不变，物理像素随缩放变化，无模糊或错位。→ Task 6 Step 9（手动检查清单）与 Task 8 的记录项。

```rust
/// Returns true if the string contains a CJK ideograph or CJK punctuation/fullwidth form.
pub fn contains_cjk(s: &str) -> bool {
    s.chars().any(|c| {
        matches!(c,
            '\u{3000}'..='\u{303F}'   // CJK symbols and punctuation
            | '\u{3400}'..='\u{4DBF}' // CJK extension A
            | '\u{4E00}'..='\u{9FFF}' // CJK unified ideographs
            | '\u{FF00}'..='\u{FFEF}' // fullwidth forms
        )
    })
}

/// Files whose content is subject to the English-only policy (06 §3.0).
pub fn should_scan(path: &Path) -> bool {
    let s = path.to_string_lossy();
    if s.starts_with("target/") || s.starts_with("docs/") || s.starts_with("locales/") || s.starts_with("i18n/") {
        return false;
    }
    matches!(path.extension().and_then(|e| e.to_str()), Some("rs") | Some("slint") | Some("toml"))
}

/// Scan one file's text and return every line containing CJK characters.
pub fn scan_text(path: &str, text: &str) -> Vec<Violation> {
    text.lines()
        .enumerate()
        .filter(|(_, line)| contains_cjk(line))
        .map(|(i, line)| Violation { path: path.to_string(), line: i + 1, text: line.trim().to_string() })
        .collect()
}
```

注意：`should_scan` 中 `toml` 扫描会覆盖 `aster.toml` 与 `Cargo.toml`，这是有意的。`locales/` 被排除。

```rust
mod policy;

use std::fs;
use std::path::{Path, PathBuf};
use std::process::ExitCode;

/// Collects file paths relative to `base`. `dir` is the directory currently being read.
fn walk(base: &Path, dir: &Path, out: &mut Vec<PathBuf>) -> std::io::Result<()> {
    for entry in fs::read_dir(dir)? {
        let path = entry?.path();
        let rel = path.strip_prefix(base).unwrap_or(&path).to_path_buf();
        let rel_str = rel.to_string_lossy();
        if rel_str == "target" || rel_str.starts_with("target/") || rel_str == ".git" || rel_str.starts_with(".git/") {
            continue;
        }
        if path.is_dir() {
            walk(base, &path, out)?;
        } else {
            out.push(rel);
        }
    }
    Ok(())
}

fn main() -> ExitCode {
    let arg = std::env::args().nth(1).unwrap_or_default();
    if arg != "check-english" {
        eprintln!("usage: cargo run -p xtask -- check-english");
        return ExitCode::from(2);
    }
    let root = std::env::current_dir().expect("INVARIANT: current directory exists");
    let mut files = Vec::new();
    if let Err(e) = walk(&root, &root, &mut files) {
        eprintln!("failed to walk repository: {e}");
        return ExitCode::from(3);
    }
    let mut count = 0;
    for rel in files.iter().filter(|p| policy::should_scan(p)) {
        let Ok(text) = fs::read_to_string(root.join(rel)) else { continue };
        for v in policy::scan_text(&rel.to_string_lossy(), &text) {
            println!("{}:{}: contains CJK text: {}", v.path, v.line, v.text);
            count += 1;
        }
    }
    if count > 0 {
        eprintln!("{count} violation(s) of the English-only policy (06 §3.0)");
        return ExitCode::from(1);
    }
    println!("english-only check passed");
    ExitCode::SUCCESS
}
```

```rust
fn broken() -> Node {
    // Deliberately broken: content minimum is too large for an 800 dp window.
    Node::new("main", Kind::Row).with_padding(48.0).with_children(vec![
        Node::new("sidebar", Kind::Leaf).with_width(Length::Dp(240.0)).with_min_width(240.0),

    assert_eq!(d.len(), 1);
    assert_eq!(d[0].code, "LAYOUT_CONFLICT");
    assert!(d[0].suggestions.iter().any(|s| s.contains("content.min_width")));

fn suggested_patch_resolves_conflict_without_changing_other_nodes() {

    let mut root = broken();
    let before_sidebar = find_mut(&mut root, "sidebar").unwrap().clone();
    find_mut(&mut root, "content").unwrap().min_width = 400.0;

}

fn patch_that_does_not_fix_root_cause_is_rejected_by_check() {

    let mut root = broken();
    find_mut(&mut root, "sidebar").unwrap().min_width = 200.0;
    assert!(!check_window(&root, 800.0).is_empty());
```
